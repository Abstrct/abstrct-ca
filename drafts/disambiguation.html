Abstrct (disambiguation)

From abstrct.ca, the website of Abstrct

Abstrct may refer to:

  • Abstrct, the handle of Josh McDougall, who puts games inside things that were not built to hold them
  • Abstract, the word, spelled correctly; not to be confused with the above
  • Abstract art, which this website was, briefly, in an earlier draft

Games

  • Schemaverse (2011), a space war played entirely in SQL, inside a PostgreSQL database; first run at DEF CON 19
  • Coindroids (2014), a robot battle game in which robots shoot money at each other; ran at DEF CON 22–28
  • Structs, a space strategy game on its own blockchain, made by Slow Ninja and played by humans and AI agents
    • pippop, Structs as a toy box
    • wyrmhodl, Structs as a sky full of dragons
    • structs.xyz, Structs as a Dreamcast game
    • Furrency, Structs as fur beasts
    • Super Structs, Structs as a Super Nintendo game (forthcoming)
  • Toronto Games, a Super Nintendo game about Toronto, written in 65816 assembly

  • AS-1, The Abstrct Standard, which he did not need to write
