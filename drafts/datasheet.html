Game Insertion Controller

Puts a game into any system not rated for one. Also known as Josh McDougall.

Features

  • Accepts databases, cryptocurrencies, blockchains and 16-bit consoles as input
  • Proven in the field: 108 players, over a million queries, four days (DEF CON 19)
  • Hot-swappable outfits for existing games
  • Rapid build mode, triggered by a conference already in progress
  • Integrated standards module (rarely engaged)
  • Audio output

Applications

  • Schemaverse: a space war in PostgreSQL
  • Coindroids: robots that shoot money, DEF CON 22–28
  • Structs: a space game on its own chain, for humans and AI agents
  • Toronto Games: a Super Nintendo game about Toronto
