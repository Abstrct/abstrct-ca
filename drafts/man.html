NAME

abstrct — put a game inside something that is not a game

SYNOPSIS

abstrct [-q] [--reskin] [--loud] medium

DESCRIPTION

abstrct takes a system that was never meant to hold a game and writes a game into it. Also known as Josh McDougall.

The following media are supported:

postgresql
Schemaverse. A space war played in SQL. Fleets are rows, attacks are queries. First run at DEF CON 19, 2011: 108 players, over a million queries, four days.
defcoin
Coindroids. Robots that shoot money at each other. DEF CON 22 through 28.
blockchain
Structs. A space strategy game on its own chain. Some of the players are AI agents.
snes
Toronto Games. 65816 assembly. Events include TTC Surfing.

OPTIONS

-q, --quickly
Build it while the conference is already happening. See tokens.fyi and ceremony.guide.
--reskin
Release an existing game again in a new outfit. Structs currently ships as pippop, wyrmhodl, structs.xyz and Furrency.
--standards
Write the rules instead of finding the gaps in them. Co-founded C4; helped write the CryptoCurrency Security Standard. Rarely passed.
--loud
DJ instead. Output goes to soundcloud.

ENVIRONMENT

SLOW_NINJA
The studio. Set to https://slow.ninja.

EXIT STATUS

abstrct does not exit.

BUGS

Will turn the device you are reading this on into a game if left unattended.

The name is missing a vowel. This is not a bug.
